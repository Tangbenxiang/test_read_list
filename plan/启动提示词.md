### 关键技术信息

- **云函数部署**：不能通过微信开发者工具部署（嵌套目录 Bug），用 API 脚本：`node scripts/deploy-function.js <函数名> garden`（需先在云控制台手动创建空函数）
- **garden_config 固定 _id**：`81704b8e6a0bffd700d3cfee1543e82c`
- **云数据库单次查询 20 条限制**
- **OpenID 比较统一用 `.toLowerCase()`**
- **项目主题色**：冰雪蓝 (#A0D6FF / #66B3FF / #0066CC)，菜园模块可适当加入绿色元素
- **页面调用云函数方式**：`wx.cloud.callFunction({ name: 'getStatus' })`（SCF 侧扁平命名，直接用函数名）
- **TabBar 页面跳转**：必须用 `wx.switchTab`，不能用 `wx.navigateTo`；switchTab 不支持 URL 参数
- **WXML 限制**：模板中不能使用 `new Date()` 或 `.map()` 等 JS 方法；style 属性不支持模板值与字面量直接拼接
- **照片上传流程**：`wx.chooseMedia` → `wx.cloud.uploadFile`（小程序端直接上传云存储）→ fileID 传给云函数
- **定时触发器配置**：在云函数目录放 `package.json`，包含 `triggers` 数组，Cron 表达式为 7 段式
