云数据库查询限制

微信云数据库单次查询最多返回 20条记录。涉及超过20条数据的场景（如书籍列表），已实现批量查询逻辑。
// 批量查询模式（pages/list/list.js）
const BATCH_SIZE = 20
let allData = []
let query = collection.where(condition)
let result = await query.limit(BATCH_SIZE).get()
while (result.data.length > 0) {
  allData = allData.concat(result.data)
  result = await query.skip(allData.length).limit(BATCH_SIZE).get()
}

开发注意事项

云函数部署流程

微信开发者工具对嵌套目录部署存在 Bug（CreateFailed 状态），使用 API 脚本部署替代：
  1. 在云开发控制台手动创建空白云函数（函数名如 getStatus，运行环境 Nodejs18.15）
    控制台地址：https://console.cloud.tencent.com/tcb/scf/index
  2. 用脚本上传代码：node scripts/deploy-function.js getStatus garden
  3. 查看所有函数状态：node scripts/deploy-function.js list
  4. 清理失败函数：node scripts/delete-failed-functions.js
  • 腾讯云 TCB 环境禁止通过 CreateFunction API 创建新函数（报 InvalidParameterValue.Stamp），必须先在控制台手动创建
  • UpdateFunctionCode API 正常可用，脚本通过此接口上传代码
  • 嵌套云函数在 SCF 侧是扁平命名的（如 garden/getStatus → SCF 函数名 getStatus）
